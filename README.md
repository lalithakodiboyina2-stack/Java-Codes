1. Electricity Bill Calculator — Methods Scenario A power company wants to automate its monthly electricity billing system. 
Each customer provides the number of units consumed during the month.
The billing system calculates the amount based on different consumption slabs. 
The first 100 units cost 2 per unit. 
The next 100 units cost 3 per unit.
Units above 200 cost 5 per unit.
Create a method calculateBill() to calculate the total bill. The method should receive units as a parameter. 
It should return the calculated bill amount.
Display the final bill to the customer. 
    Input Format 250 
    Output Format 750
